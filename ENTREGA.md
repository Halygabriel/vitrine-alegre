# ENTREGA — passos finais que dependem da sua conta

O código do projeto está preparado. Estes passos precisam ser feitos por você porque dependem das suas contas do GitHub e da Vercel.

## 1. GitHub

O nome exigido é:

```text
vitrine-alegre
```

Endereço esperado usando o usuário informado no desenvolvimento:

```text
https://github.com/Halygabriel/vitrine-alegre
```

O repositório deve ser público.

Não envie `node_modules/`.

## 2. Histórico

A atividade exige commits ao longo do processo. Não crie um histórico falso somente para preencher a rubrica. Use o histórico real que já existe e, daqui em diante, faça commit de cada mudança real: revisão da documentação, configuração do deploy, correção encontrada nos testes e atualização do link final.

Exemplos de mensagens descritivas para mudanças que você realmente fizer:

```text
docs: revisa README e diario da IA
fix: ajusta comportamento encontrado no teste de deploy
chore: confirma configuracao da Vercel
docs: adiciona URL publica da Vercel
```

## 3. Vercel

Importe o repositório no Vercel e faça o deploy. Não é necessário alterar o código para criar o link.

Depois do deploy, copie a URL real, teste `/products/1` com F5 e atualize o topo do `README.md`.

## 4. Campo de texto da tarefa

Cole apenas os dois links públicos finais:

```text
https://github.com/Halygabriel/vitrine-alegre
https://SEU-LINK-REAL-DA-VERCEL.vercel.app
```

O segundo endereço acima é apenas um modelo. Use o que a Vercel realmente gerar.
